# Worked Example — 六版 Design Critique 信息图

## 背景

教学目标：用一张图说明 *Language of Design — Critique Framework* 的八个评价维度和三个等级，让设计学习者理解并学会应用；基于连续六次生图、评价和修改的讨论做复盘。这里记的是主要迭代发现，**不是基于独立的用户研究或定量实验**。

| Version | 本轮设计重点 | 主要 Critique | 下一轮选择 |
|---|---|---|---|
| **V1** | 日落/山景/旅人插画围绕八个提问 | 风景有吸引力，但与评价框架的功能和意义无关；阅读顺序曲折 | 移除无关装饰，明确层级和网格 |
| **V2** | 2×4 八维网格，设计问题清晰 | 解释“评价什么”，但没有展示三档标准怎么使用 | 增加 8×3 评价矩阵与具体示例 |
| **V3** | 完整八维 × 三档矩阵 + 案例 | 评价更系统，但信息过载，例子太小且部分判断缺少证据 | 聚焦案例，让评级与证据一一对应 |
| **V4** | 左侧案例、右侧八维逐项点评 | 评分证据映射仍有偏差；Before/After 改动差异过小，不可有效检验 | 强化真实前后对照，说明修改 |
| **V5** | 真实 Before / After，逐项解释修改 | 变化可见，但只有 Before 评分，缺少 Re-evaluation | 增加修改后独立复评与证据关联 |
| **V6** | Before/After 八维评分、具体改动与影响 | 八个 After 全 Strong 过于整齐；部分分数缺证据，视觉专家评价被误称为“可测效果” | 校准判断，区分可见改进与用户效果，必要时停止而不凑 V7 |

## 从案例得到的稳定规则

1. **美感不是目标的替代品。** V1 失败在 Meaning/Function 与装饰脱节。
2. **信息完整度不能抵消拥挤。** V3 与 V6 表明加入更多文字可能使 Audience/Composition 倒退。
3. **评价必须先观察再判断。** “用户更喜欢”“任务更容易”不是由图像本身直接证明的事实。
4. **修改必须可见、可追溯、可比较。** 只有新旧图片并列还不够，还要指出修改点与受影响维度。
5. **改进不意味着所有分数上涨。** 同一 AI 生成与评价需要自我校准，保留 Fair 与 Unknown。
6. **持续优化有停止点。** 版本号增长不是质量提升的证据；当目标达到且缺少新证据时可停止。

## 有意保留的边界

这次实操验证的是该工作流能持续引出更细致的设计判断和可见的作品变化；它**没有**通过独立专家评分一致性检验、读者任务完成率或 A/B 实验来证明教学效果与用户效果的提高。
