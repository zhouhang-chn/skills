# Skills

Reusable skills for AI agents and coding assistants, independent of any single platform.

- [time-series-storytelling](time-series-storytelling/SKILL.md): Generate evidence-bound time-series narrative plans and reproducible video with a deterministic Python runtime.
- [html-dashboard](html-dashboard/SKILL.md): Generate self-contained, interactive offline HTML dashboards with traceable evidence.
- [change-request](change-request/SKILL.md): Draft self-contained, evidence-grounded change proposals with explicit boundaries and acceptance criteria.
- [minimize-change](minimize-change/SKILL.md): Review completed changes for sufficiency and necessity before commit.
- [skill-minimizer](skill-minimizer/SKILL.md): Minimize a skill while preserving its intended behavior.
- [meta-research](meta-research/SKILL.md): Graph-guided research for broader source coverage through lexical, semantic, relational, and temporal expansion.
- [repo-study](repo-study/SKILL.md): Trace repository implementation, dependencies, Git evolution, author rationale, third-party evidence, and reusable lessons.
- [x-post](x-post/SKILL.md): Write or rewrite concise technical X posts in a human, thinking-in-public style.
- [x-article](x-article/SKILL.md): Turn existing work and research into evidence-backed, visually structured long-form X Articles.
- [visual-explain](visual-explain/SKILL.md): Create accurate explanatory visuals for structures, processes, comparisons, teaching, and evidence.
- [visual-story](visual-story/SKILL.md): Turn article sections, ideas, or talks into coherent single-image or multi-image visual narratives.
- [visual-art-direction](visual-art-direction/SKILL.md): Explore and refine visual styles for avatars, covers, illustrations, and reference-based edits.
- [visual-iterate](visual-iterate/SKILL.md): Improve static visuals through evidence-based critique, targeted revisions, and before/after re-evaluation.

See the [Visual Skills guide](docs/visual-skills.md) for routing and usage, and [evaluation cases](evals/visual-skills/README.md) for behavioral acceptance checks.
