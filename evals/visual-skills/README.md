# 验收用例

这些用例检验可观察行为，而不是提示词是否包含某个词。
覆盖正常请求、歧义、边界、组合任务、诱发错误的修改、证据时效和交付。

## 怎么用
向具备所需工具的目标 Agent 提供一个用例及必要参考/资料，启用对应 skill。
检查它实际取得了哪些输入、形成的可见工作规格和最终交付，而不请求或评估私有思维过程。
逐项核对 `must` 与 `must_not`，记录通过、失败或未测；条件不足时，正确澄清也可以是期望行为。
包含图片修改的用例需提供真实前置图片；A02 专门测试目标缺失，不应伪造参考。
涉及当前版本的 E03 需在执行当日真实检索，不能沿用本包编写日的假定。

## 分开验收
语义验收：对象、方向、条件、数值、范围、证据边界是否正确。
视觉验收：实际图片是否按这些约束呈现，文字是否可读，视觉层级是否服务任务。
交付验收：图片/文件真实存在、可访问，且没有多做未经请求的发布或写操作。
任何硬性语义错误都不能用“很好看”抵消。
